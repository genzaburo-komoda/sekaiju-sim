# 世界樹の迷宮Ⅰ HD REMASTER パーティ構築シミュレーター（非公式・β版）

『世界樹の迷宮Ⅰ HD REMASTER』のパーティ構築（スキルの振り方）を計算・最適化・採点するウェブアプリです。数値は Steam版を基準にしています。

公開ページ：https://genzaburo-komoda.github.io/sekaiju-sim/

本ツールは非公式のファンツールであり、株式会社アトラスおよび株式会社セガとは一切関係ありません。『世界樹の迷宮』に関する著作権その他の権利は、各権利者に帰属します。ゲームの画像・音声・ロゴは使っていません。

## できること

- パーティ編成（最大5人・隊列・難易度）、スキル振り分け（前提スキルの自動取得、SP の制約）、引退ボーナス
- ダメージ計算と計算根拠の表示、ゲーム内の実測との比較
- 最適化：最大ダメージ、状態異常を付ける確率、回復の効率
- 採点：役割ごとの点数（火力・状態異常・回復・耐久・探索）、改善案、次に振るスキル、役割バランス（基準は仮）
- 戦闘シミュレーション：行動順・強化の持続・TP を追った撃破までの最小ターン数、乱数で何度も戦った確率分布、敵の攻撃に何ターン耐えるか
- 保存・URL での共有・テキストの書き出し

## 数値の確かさと免責

数値と計算式は、世界樹の迷宮 Wiki（atwiki）、英語版 Etrian Odyssey Wiki、敵データの解析スプレッドシートなどの資料と、ゲーム内での実測をもとにしています。多くは DS版の記述・解析による値で、Steam版では未検証です。画面には確度（確認済み・推定・未検証）を表示しています。

計算結果の正確さは保証しません。このツールを使ったことによる損害について、作者は責任を負いません。

## プライバシー

個人情報は集めません。アクセス解析は入れていません。構築と実測記録は、使っているブラウザの中（localStorage）にだけ保存されます。

## 開発

```bash
npm ci
npm run dev      # 開発サーバー
npm test         # 自動テスト
npm run build    # 型の検査と公開用の組み立て
npm run lint     # 書き方の検査
```

技術構成：React + TypeScript + Vite。main に push すると GitHub Actions がテストと組み立てを行い、GitHub Pages に公開します（`.github/workflows/deploy.yml`）。
